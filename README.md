# Рынок — поиск и анализ вакансий

Next.js-сервис ищет до 20 английских вакансий за последние 7 дней по отдельной стране или по всему миру. Единственный источник — Apify Actor `fantastic-jobs/career-site-job-listing-api`. Найденные позиции передаются в структурированный русскоязычный анализ OpenRouter-модели `google/gemini-3.7-flash`.

## Локальный запуск

1. Установите зависимости: `pnpm install`.
2. Скопируйте `.env.example` в `.env.local` и заполните ключи.
3. Запустите: `pnpm dev`.
4. Откройте `http://localhost:3000`.

Секреты `APIFY_API_TOKEN`, `OPENROUTER_API_KEY` и `TURNSTILE_SECRET_KEY` используются только в серверном Route Handler. Публичным является только `NEXT_PUBLIC_TURNSTILE_SITE_KEY`.

Готовые профессии показываются в форме по-русски, но отправляются в поиск по-английски. Произвольное название не переводится автоматически, поэтому для него рекомендуется английский язык.

## Проверка

- `pnpm test` — модульные тесты.
- `pnpm typecheck` — проверка TypeScript.
- `pnpm build` — production-сборка Next.js.

В браузере хранится не более пяти результатов; одинаковый запрос может быть взят из локального кэша в течение 6 часов. Это защита демонстрационного проекта, а не строгий серверный лимит.
