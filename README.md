# Рынок — поиск и анализ вакансий

Next.js-сервис с обязательной регистрацией ищет до 20 английских вакансий за последние 7 дней по отдельной стране или по всему миру. Единственный источник — Apify Actor `fantastic-jobs/career-site-job-listing-api`. Найденные позиции передаются в структурированный русскоязычный анализ OpenRouter-модели `google/gemini-3.7-flash`.

Регистрация и баланс хранятся в Supabase. Новый пользователь получает 5 кредитов, один новый непустой анализ расходует 1 кредит. Повтор сохранённого результата и один повтор AI после ошибки не требуют дополнительного кредита.

## Локальный запуск

1. Установите зависимости: `pnpm install`.
2. Скопируйте `.env.example` в `.env.local` и заполните ключи.
3. Запустите: `pnpm dev`.
4. Откройте `http://localhost:3000`.

Секреты `APIFY_API_TOKEN`, `OPENROUTER_API_KEY` и `TURNSTILE_SECRET_KEY` используются только на сервере. Публичными являются настройки Turnstile и publishable key Supabase; доступ к пользовательским данным ограничен RLS-политиками базы.

Готовые профессии показываются в форме по-русски, но отправляются в поиск по-английски. Произвольное название не переводится автоматически, поэтому для него рекомендуется английский язык.

## Проверка

- `pnpm test` — модульные тесты.
- `pnpm typecheck` — проверка TypeScript.
- `pnpm build` — production-сборка Next.js.

В браузере хранится не более пяти результатов; одинаковый запрос может быть взят из локального кэша в течение 6 часов. Лимит анализов обеспечивается серверным балансом Supabase, а не localStorage.
