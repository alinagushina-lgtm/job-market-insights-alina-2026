# Глобальный поиск английских вакансий через Apify

Дата: 24 августа 2026 года  
Статус: согласовано в диалоге, ожидает просмотра перед реализацией

## 1. Цель

Полностью удалить прежнюю российскую интеграцию и вернуть сервис к единственному источнику вакансий — Apify Actor `fantastic-jobs/career-site-job-listing-api`. Расширить географию поиска с России и стран СНГ до всего мира и упростить ввод профессии с помощью русскоязычных подсказок, которые преобразуются в английские поисковые запросы.

Интерфейс и аналитический отчёт остаются русскоязычными. Названия вакансий, компаний и исходные данные не переводятся и показываются так, как их вернул источник.

## 2. Границы изменения

В изменение входят:

- полное удаление кода, тестов, конфигурации и документации прежнего источника;
- единый поиск через Apify для любой страны и для варианта «Весь мир»;
- встроенный справочник стран с русскими подписями и английскими значениями для Apify;
- комбинированный ввод профессии: готовые варианты и произвольный текст;
- английские поисковые значения для готовых русских названий профессий;
- автоматический выбор основной валюты страны с возможностью ручной замены;
- сброс старого браузерного кэша повышением версии ключа;
- локальная и публичная проверка полного пользовательского сценария.

В изменение не входят:

- автоматический перевод произвольного названия профессии;
- перевод вакансий на русский язык;
- валютная конвертация зарплат;
- регистрация пользователей;
- новый внешний географический API;
- изменение визуального стиля сайта;
- изменение существующей интеграции OpenRouter и Turnstile, кроме необходимой адаптации типов формы.

## 3. Профессии

Поле профессии позволяет выбрать готовый вариант или ввести собственное название. Готовый вариант отображается по-русски, но в запрос Apify передаётся английское поисковое значение.

Начальный список:

| Подпись | Запрос Apify |
| --- | --- |
| Разработчик ПО | Software Developer |
| Аналитик данных | Data Analyst |
| Бизнес-аналитик | Business Analyst |
| Тестировщик | QA Engineer |
| DevOps-инженер | DevOps Engineer |
| Менеджер проектов | Project Manager |
| Продакт-менеджер | Product Manager |
| UX/UI-дизайнер | UX/UI Designer |
| Маркетолог | Marketing Specialist |
| Менеджер по продажам | Sales Manager |
| Специалист поддержки | Customer Support Specialist |
| HR-специалист | HR Specialist |
| Рекрутер | Recruiter |
| Бухгалтер | Accountant |
| Финансовый аналитик | Financial Analyst |
| Юрист | Lawyer |

Если пользователь вводит собственное название, оно передаётся без перевода. Рядом с полем показывается нейтральная подсказка: «Для лучших результатов вводите профессию по-английски». Дополнительное название профессии продолжает работать как второй поисковый вариант и также не переводится автоматически.

## 4. Страны, города и валюты

Страна выбирается из поискового списка всех поддерживаемых суверенных государств. Подписи показываются по-русски, а в Apify передаются английские названия. Первым вариантом является «Весь мир».

Популярные страны закрепляются в начале списка: Россия, США, Великобритания, Германия, Франция, Испания, ОАЭ, Канада, Нидерланды и Казахстан. Ниже доступен полный список без повторов.

При выборе конкретной страны:

- город остаётся необязательным;
- известные русские названия городов преобразуются в английские, остальные транслитерируются;
- основная валюта страны подставляется в поле зарплаты автоматически;
- пользователь может вручную выбрать другую поддерживаемую валюту.

При выборе «Весь мир»:

- Apify не получает ограничение `locationSearch`;
- город очищается и отключается;
- валютой по умолчанию становится USD;
- минимальная зарплата остаётся необязательной.

Зарплаты не конвертируются. Существующая классификация сравнивает только вакансии с сопоставимой валютой и периодом оплаты.

## 5. Архитектура и поток данных

Единый поток запроса:

`форма → Turnstile → Apify → нормализация → список вакансий → OpenRouter → отчёт`.

Серверный модуль поиска всегда вызывает Apify. Ветвление по России, резервный источник и типы ошибок прежней интеграции удаляются. Ошибки Apify преобразуются в существующий безопасный тип ошибки поиска без вывода ключей или внутренних ответов сервиса.

Справочники профессий, стран и валют размещаются в независимых модулях. Схема формы принимает глобальный код страны и поддерживает специальное значение для поиска по всему миру. Построитель Apify input отвечает только за преобразование нормализованной формы в формат Actor.

OpenRouter получает прежний внутренний тип нормализованной вакансии, поэтому логика отчёта не зависит от расширения географии.

## 6. Интерфейс

Поле профессии работает как доступное комбинированное поле: готовые подсказки можно выбрать клавиатурой или мышью, но произвольный ввод не блокируется.

Поле страны работает как доступный поисковый список. Выбор страны обновляет валюту только автоматически; последующая ручная замена валюты не должна неожиданно сбрасываться до нового выбора страны.

Для варианта «Весь мир» отключённое поле города получает понятное пояснение. Пустая выдача сообщает: «Английских вакансий по этому сочетанию профессии и места не найдено. Попробуйте английское название, другую страну или поиск по всему миру».

Существующие карточки вакансий, потоковые статусы, отчёт, история и визуальный стиль сохраняются.

## 7. Удаление прежней интеграции

Удаляются:

- отдельный каталог прежней интеграции вместе с тестами;
- её импорты, маршрутизация и тексты в `lib/jobs/search.ts`;
- её серверная переменная из `.env.example` и инструкций;
- разделы README про прежнюю авторизацию;
- спецификации `2026-08-24-hh-public-search-design.md` и `2026-08-24-hh-application-auth-design.md`.

После удаления поиск по исходникам не должен находить название, секрет или импорты прежней интеграции. Сгенерированные артефакты сборки не считаются исходным кодом и пересоздаются при проверке.

## 8. Кэш и обратная совместимость

Формат страны и логика источника меняются, поэтому версия ключа браузерного кэша повышается. Старые результаты, полученные через прежний источник, не читаются новым интерфейсом и не показываются в истории.

Миграция старой истории не выполняется: это локальные временные данные демонстрационного сервиса, а смешивание источников создало бы неверные ожидания.

## 9. Ошибки

- Если Apify не настроен, показывается сообщение о временной недоступности поиска без упоминания имени секрета.
- Если Apify отклоняет ключ, пользователь получает безопасное сообщение о недоступности сервиса.
- При тайм-ауте предлагается повторить запрос или сузить географию.
- При пустой выдаче список остаётся видимым с подсказкой изменить профессию или место.
- Если OpenRouter недоступен, реальные вакансии остаются на экране.
- Демонстрационные или выдуманные вакансии не подставляются.

## 10. Проверка

Автоматические проверки:

1. Тест русской готовой профессии и её английского поискового значения.
2. Тест произвольного названия без автоматического перевода.
3. Тест конкретной страны, английского названия и основной валюты.
4. Тест «Весь мир» без `locationSearch` и с USD по умолчанию.
5. Тест города и транслитерации.
6. Существующие тесты нормализации Apify, зарплат, истории, Turnstile и OpenRouter.
7. Поиск отсутствующих упоминаний прежнего источника в исходниках.
8. `pnpm test`, `pnpm run typecheck` и `pnpm run build`.

Пользовательская проверка:

1. Выбрать готовую профессию и конкретную страну.
2. Убедиться, что появились реальные английские вакансии с исходными ссылками.
3. Выполнить поиск по варианту «Весь мир».
4. Проверить произвольную профессию.
5. Проверить форму на компьютере и мобильной ширине.
6. Подтвердить, что вакансии появляются до завершения анализа.
7. Подтвердить, что аналитика OpenRouter остаётся русскоязычной.

## 11. Публикация и критерии готовности

После успешных локальных проверок создаётся production-развёртывание существующего проекта Vercel. Публичная версия считается готовой, когда:

- на сайте нет упоминаний и вызовов прежнего источника;
- поиск любой страны и вариант «Весь мир» используют только Apify;
- профессия выбирается из русских подсказок или вводится вручную;
- выбранная подсказка формирует английский запрос;
- реальные английские вакансии отображаются списком;
- OpenRouter формирует русский отчёт;
- Turnstile, кэш и локальная история работают;
- секреты отсутствуют в клиентском коде и ответах;
- тесты, TypeScript и production-сборка проходят;
- полный сценарий проверен на публичном URL как обычным посетителем.
